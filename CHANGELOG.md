# Changelog

## 0.10.2 — 2026-11-17

- New Raid Atlas identity: an amber navigation mark, macOS app icon, interface logo and favicon.
- Redesigned Russian README, English overview, screenshot cover, animated preview and a 60-second 1080p promo with an original procedural score.
- Reproducible media capture/render scripts using the actual app interface.
- One `VERSION` file controls bundle metadata, the window title and installer filenames.
- Documented releases, checksums, a manual workflow that prepares draft releases and structured bug reports.
- Maps, catalog and route calculations are unchanged from 0.10.1.

## 0.10.1 — 2026-11-17

First public macOS release: offline maps, 338 PvE quests, 134 extraction records, faction filtering, floor plans, room search, gear lists and route planning. Universal DMG with ad-hoc signing and SHA-256. 39 automated tests and a native exit audit across 12 maps / 14 views.
