- [Русские титры SRT](https://github.com/Estoutic/raid-atlas/releases/download/v0.10.2/Raid-Atlas-Promo-ru.srt).

Кадры показывают настоящий интерфейс Raid Atlas. Сценарии выполнены в отдельном непостоянном профиле браузера: задания, подготовка, поиск комнаты и этажа, рассчитанный маршрут, сравнение выходов, вращение 3D-Завода и ручной план. Анимация титров, приближения и рамка окна добавлены при монтаже; это смонтированная демонстрация, не непрерывная запись действий пользователя. В ролике нет голосовой озвучки.

## Повторная сборка

Нужны Node.js 22+, npm, FFmpeg и установленный Google Chrome. Альтернативный Chromium можно задать абсолютным путём через `PROMO_CHROME`.

```sh
cd promo
npm ci
npm run capture
npm run render
sh export.sh
```

`capture.cjs` запускает сервер только на `127.0.0.1` и отдельный headless-профиль. `render.cjs` формирует MP4 и SRT в `releases/`, обложку в `docs/media/`. `render.cjs --preview` создаёт только обложку и контрольные кадры. Звуковая дорожка синтезируется `soundtrack.cjs`, без сторонних сэмплов. Временные кадры вращения и WAV лежат в игнорируемом `cache/`.

Отчёт захвата: [checks/promo-capture.json](../checks/promo-capture.json). Для перепроверки титров: `film.html`; монтаж привязан ко времени и не зависит от CSS-таймеров.

## Визуальный язык

Янтарный `#f3c553`, ночной синий `#0b111a`, светлый текст `#f4f2ea`. Знак объединяет A, стрелку направления и путь к точке. Логотип создан встроенным imagegen; [точный промпт и происхождение](../app/assets/GENERATION.md). Web- и ICNS-версии получены изменением формата/размера исходного PNG, без ретуши.
