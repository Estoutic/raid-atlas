## Новый монтаж

Лес → обновлённая Таможня → Берег → Развязка → Завод. На Таможне нажимается расчёт маршрута, на Береге поиск открывает комнату 306 западного крыла на третьем этаже. На Развязке переключаются этажи, на Заводе вращается настоящая 3D-модель. Ледокола в этом ролике нет.

Это записи действий в настоящем интерфейсе, смонтированные с ускорением, приближениями камеры и короткими переходами под музыку. Курсор следует реальным событиям мыши; кольцо клика добавлено при записи. Профиль браузера временный, данные пользователя не используются. Модели загружены перед записью. Постоянных плашек, номеров сцен и нижних титров нет; название карты появляется меньше чем на секунду. Озвучки нет.

Музыка: **[Venom — Scott Buckley](https://www.scottbuckley.com.au/library/venom/)**, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Использован фрагмент с затуханием и выравниванием громкости. [Полная атрибуция и текст для публикаций](MUSIC.md).

## Повторная сборка

Нужны Node.js 22+, npm, FFmpeg и Google Chrome. Другой Chromium можно указать через `PROMO_CHROME`.

```sh
cd promo
npm ci
sh music.sh
npm run capture
npm run render
sh export.sh
```

`capture-v2.cjs` записывает пять сцен в отдельных контекстах Playwright. Сервер слушает только `127.0.0.1`. `render-v2.cjs` собирает MP4 из записей и выбранной музыки; тайминг и камера заданы в `film-v2.html`. Временные MP4, WebM и исходная музыка хранятся в игнорируемом `cache/promo-v2/`, финал — в `releases/`.

Для контрольных кадров: `node render-v2.cjs --preview`. Для повторной записи одной карты: `node capture-v2.cjs factory`. [Отчёт захвата](../checks/promo-v2-capture.json). Старые `capture.cjs`, `render.cjs`, `film.html` и `soundtrack.cjs` сохраняют исходники первого монтажа и не используются текущими npm-командами.
